# Security Policy

## Reporting Security Issues

If you discover a security vulnerability in **Razer AIKit**, please report it responsibly.  
Do not disclose the issue publicly until it has been reviewed and addressed by the maintainers.

You can report security issues by emailing: [developer@razer.com](mailto:developer@razer.com)

We will acknowledge receipt of your report within a reasonable time frame and work with you to understand and resolve the issue quickly.

---

## Supported Versions

We aim to keep the latest release of Razer AIKit secure.  
Please update to the most recent version to benefit from security fixes and improvements.

---

## Guidelines

- Do not test vulnerabilities on production systems without permission.  
- Provide as much detail as possible in your report (steps to reproduce, potential impact, etc.).  
- Keep communications confidential until a fix is released.  

Thank you for helping keep **Razer AIKit** safe and secure.
