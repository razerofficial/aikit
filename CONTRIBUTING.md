# Contributing to Razer AIKit

Thank you for your interest in contributing to **Razer AIKit**, an R&D toolkit for Large Language Models (LLMs).

## Code of Conduct

This project and everyone participating in it are governed by our [Code of Conduct](CODE_OF_CONDUCT.md). By participating, you agree to uphold responsible AI practices and ethical development standards.

## How to Contribute

Since this project will be published on GitHub, all contributions must come through GitHub's standard workflow.

### 1. Reporting Issues

- **Check existing issues** before creating new ones
- **Use issue templates** when available
- **Provide clear descriptions** with steps to reproduce
- **Include environment details** (OS, Python version, GPU info)

### 2. Suggesting Features

- **Open a GitHub issue** with the enhancement label
- **Describe the problem** you're trying to solve
- **Propose a solution** with examples if possible

### 3. Contributing Code

1. **Fork** the repository on GitHub
2. **Create a branch** for your changes:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. **Make your changes** following our coding standards
4. **Test your changes** thoroughly
5. **Commit** with clear, descriptive messages
6. **Submit a pull request** to the main repository

## Pull Request Guidelines

- **Clear title** and description
- **Link related issues** (e.g., "Fixes #123")
- **Include tests** for new functionality
- **Update documentation** if needed
- **Follow code style** and conventions
- **Ensure CI checks pass**

## Development Standards

- Follow **PEP 8** for Python code style
- Include **type hints** for function signatures
- Write **clear docstrings** for public functions
- Add **tests** for new features and bug fixes
- Keep **commits focused** and atomic

## Responsible AI Guidelines

All contributions must align with our commitment to responsible AI:

- **Test for bias** and fairness in AI components
- **Consider privacy** implications of data handling
- **Document potential risks** or limitations
- **Avoid harmful applications** or use cases

## Getting Help

- **GitHub Issues**: For bugs and feature requests
- **GitHub Discussions**: For questions and community support
- **Security Issues**: Follow our [Security Policy](SECURITY.md)
